## Fonts

Decks use **Arial**, which ships with Windows and macOS — nothing to install, nothing to license.

> [!CAUTION]
> Proxima Nova is licensed through Adobe Fonts; the kit to load for web work is `uth1qfm`
> (`https://use.typekit.net/uth1qfm.css`), which serves the full 400–800 range. **Do not embed it in a
> document and do not attach a font file to a deck** — kits serve fonts from Adobe's CDN and grant no
> right to redistribute the binaries. See the plugin README.
