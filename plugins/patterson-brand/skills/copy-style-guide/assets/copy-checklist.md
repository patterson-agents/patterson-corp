# Patterson copy proofreading checklist

> [!IMPORTANT]
> Cite the rule and its source for every failure. Do not invent rules.

---

## Case

- [ ] Headline is sentence case `[BG25 p.59]`
- [ ] Subheads and body are sentence case `[BG25 p.59]`
- [ ] Button and CTA labels are sentence case `[BG25 p.57]`
- [ ] Email subject line and preheader are sentence case `[BG25 p.58]`
- [ ] Eyebrows and text links are sentence case `[DS20 p.10]`
- [ ] Any all-caps is one of the three exceptions: print title, footer/title text, email-signature
      promise line

## Brand promise and legal

- [ ] Running copy: *Trusted Expertise, Unrivaled Support* — comma, no ® `[BG25 p.6]`
- [ ] Designed graphic: *Trusted Expertise. Unrivaled Support.®* — periods, ®, once per piece
- [ ] Promise is not quoted in copy, and not used as a headline outside whole-company pieces
- [ ] No `Inc.` or `Co.` anywhere in the copy `[BG25 p.10]`
- [ ] ® not ™ `[BG25 p.28]`

## Numbers, dates, money, time

- [ ] Zero–nine spelled out; 10+ in numerals; numerals for ages, dates, dimensions, percentages,
      measures and weights
- [ ] Percent uses the `%` symbol
- [ ] Leading zero on decimals under 1
- [ ] Marketing dollars drop `.00`; financial copy keeps cents
- [ ] Dates written in full — no abbreviations, no *-st*/*-rd*
- [ ] Ranges use an **en dash with spaces**: `6:30 – 7 p.m.`
- [ ] Times drop `:00` on the hour; lowercase `a.m.` / `p.m.` with periods
- [ ] Phone numbers use **periods**, no leading "1" on toll-free, comma before an extension
- [ ] Units have a space before them; `mL` for Veterinary

## Punctuation

- [ ] **No serial comma** in a simple series; serial comma used in a complex one
- [ ] One space after a period
- [ ] Colon before a list only after a complete sentence
- [ ] Exclamation points used sparingly
- [ ] Periods and commas inside quotation marks
- [ ] Academic degrees have no periods (DDS, DVM, RDH, PhD)
- [ ] Brackets, not parentheses, inside quoted material
- [ ] Ampersand used only where permitted

## CTAs and links

- [ ] One CTA; never more than three `[BG25 p.10]`
- [ ] No punctuation in the button label `[DS20 p.10]`
- [ ] No phone number in a button
- [ ] CTA is not a question
- [ ] Email link text does not display the raw address
- [ ] Site directions italicized, with angle brackets and a bolded action word
- [ ] URLs lowercase, no `http://`, short form verified to resolve

## Naming and terminology

- [ ] *Patterson Veterinary* on first reference; *Patterson Vet* only afterwards and never in legal
      copy
- [ ] *Patterson Animal Health* does not appear in customer-facing copy
- [ ] Product name spacing exact (*TechEdge*, *DesignEdge*, *A-dec*, *HIPAA*, *NewTom*)
- [ ] No graphic treatment recreated in text (*Prana*, not *prAna*)
- [ ] Sales titles correct for the unit — territory representatives (Dental), territory managers
      (Veterinary), OSRs/ISRs (Animal Health)
- [ ] Veterinary terms: *patient*, *exam room*, *clinic*/*hospital*; *Elizabethan collar*
- [ ] *Dr.* not combined with a degree abbreviation
- [ ] Job title capitalized only before a name

## Style

- [ ] Active voice throughout `[BG25 p.11]`
- [ ] One thought per sentence
- [ ] No *great, special, really, very*
- [ ] No internal jargon — customer's words used
- [ ] Content is scannable: clear headlines and subheads `[BG25 p.11–12]`
- [ ] AP style overall; AMA style if it is a medical article
